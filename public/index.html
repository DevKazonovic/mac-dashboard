Checking your Mac…

Memory

How your RAM is split right now. Apps is what open apps use, macOS is what the system keeps for itself, Compressed is memory macOS squeezed to make room, and Available is free or holds files macOS can drop at once. The badge is macOS’s own measure of how hard it works to find memory.

Swap Disk space macOS uses as extra RAM once RAM is full. A little is normal. Several GB means apps keep waiting for the disk.

Processor

How busy all the processor cores are together, over the last 5 seconds. Busiest names the app using the biggest share of the whole processor.

Disk

Free space on your Mac’s main disk. macOS needs room for swap, updates and caches, and slows down when it runs short.
